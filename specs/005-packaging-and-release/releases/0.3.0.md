# Release 0.3.0: gate record

Quiet mode (spec 011, roadmap F7): `-q` / `--quiet` before or after the command name, and `DNM_QUIET=1`, hide
warnings and notes and never results or errors. `dnm cleanup --scan` (spec 012, roadmap F9): visits every Desktop
of every connected display with the Accessibility permission, as `--desktop` does, and offers to delete the labels
that no Desktop shows. Written by `scripts/release.sh` and the maintainer; committed after publishing (FR-017).
Feature F6 (spec 013) was planned for 0.3.0 on 2026-11-11 and closed the same day: known issue KI-3 did not
reproduce. Contains no credential, personal path or identifier.

## Release

- Version: 0.3.0, build set by `just release` (tag `v0.3.0`, commit "Release 0.3.0 build N")
- Run by: maintainer, with Claude Code
- A minor release with no breaking changes: every command behaves as in 0.2.2 without `-q` or `--scan`; the
  `cleanup --json` document gains a `mode` field; no stored data changes (format 3, as in 0.2.2). A new exit status,
  130, for a scan stopped with Ctrl-C.

## Review notes

### Security review

Fresh agent, range `v0.2.2..012-cleanup-scan` at `3a6b4f4` (2026-11-09). No high finding. Accessibility is opt-in,
checked without prompting and used only by `--desktop` and `--scan`; no network, telemetry or private interface;
deletion stays in the store and in the agreed, re-checked list; quiet mode hides only warnings and notes.

1. Medium: keys typed during the scan could answer the delete question. Fixed in `d9fb25d` (the terminal's input is
   flushed before each question).
2. Low: a second-Ctrl-C line could be garbled if the signal is handled on another thread while the line is being
   prepared. Accepted: no memory-safety risk, and the process exits 130 either way.
3. Low: `Tests/live/live-syntax.sh` could clean up through the quiet-mode store after an early exit. Fixed in
   `d9fb25d`.
- Open questions: whether macOS consumes Control-arrow at the first and last Desktop (else the frontmost app gets
  it; true for `--desktop` too); live checks.
