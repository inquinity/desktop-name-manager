# Release 0.5.0: gate record

macOS 27 or later, Apple silicon only. 0.4.0 was the first and only release for macOS 26; from 0.5.0 the cask says
`depends_on macos: :golden_gate` and `arch: :arm64`, the app and `dnm` need macOS 27, and the stand-in wallpaper refusal
([spec 015](../../015-default-placeholder/spec.md)) is always on. The decision and its reasons are in
[spec 005, Session 2026-11-24](../spec.md). Written by `scripts/release.sh` and the maintainer; committed after
publishing (FR-017). Contains no credential, personal path or identifier.

## Release

- Version: 0.5.0, build set by `just release` (tag `v0.5.0`, commit "Release 0.5.0 build N")
- Run by: maintainer, with Claude Code
- A minor release: the minimum OS moves from macOS 26 to macOS 27; otherwise the changes since 0.4.0 are listed in
  `docs/release-notes/0.5.0.md`. Users on macOS 26 stay on 0.4.0; the cask refuses to install this release there.

`docs/release-notes/0.5.0.md`, composed by `just release` from `docs/release-notes/UNRELEASED.md`.

## Maintainer gates

Checked by the maintainer; `scripts/release.sh 0.5.0 check` refuses to run while any is unchecked.

- [ ] Reviews: independent reviews, each by a separate agent with fresh context, given only the range
  `v0.4.0..<release commit>`; then a fresh re-review of any fix commits. Results under "Review notes".
- [ ] Live confirmation, on the maintainer's Mac (macOS 27, Apple silicon), each run with a private store and an
  `Index.plist` backup, ending with the labels removed. Still open from 0.4.0
  ([spec 014 tasks.md](../../014-menu-bar-app/tasks.md)): T037 (timing, first use), T053 (VoiceOver), T059 (a fresh
  account), and a 0.3.0 or later `dnm` reading labels made through the app's own window.
- [ ] Upgrade from 0.4.0 (spec 005 User Story 3): `brew upgrade --cask` from the installed 0.4.0 (the app layout to the
  app layout); the label made with 0.4.0 still shows, and `dnm show`, `dnm undo` and `dnm remove` work.
