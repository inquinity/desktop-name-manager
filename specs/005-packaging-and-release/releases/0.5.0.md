# Release 0.5.0: gate record

macOS 27 or later, Apple silicon only. 0.4.0 was the first and only release for macOS 26; from 0.5.0 the cask says
`depends_on macos: :golden_gate` and `arch: :arm64`, the app and `dnm` need macOS 27, and the stand-in wallpaper refusal
([spec 015](../../015-default-placeholder/spec.md)) is always on. The decision and its reasons are in
[spec 005, Session 2026-11-24](../spec.md). Written by `scripts/release.sh` and the maintainer; committed after
publishing (FR-017). Contains no credential, personal path or identifier.

## Release

- Version: 0.5.0, build set by `just release` (tag `v0.5.0`, commit "Release 0.5.0 build N")
- Run by: maintainer, with Claude Code
- A minor release: the minimum OS moves from macOS 26 to macOS 27; otherwise the changes since 0.4.0 are listed in
  `docs/release-notes/0.5.0.md`. Users on macOS 26 stay on 0.4.0; the cask refuses to install this release there.

## Release checks

During the procedure, after the gates above; ticked as each is done.

- [x] Upgrade from 0.4.0 (spec 005 User Story 3), after the cask was in the tap, 2026-11-24, macOS 27.2.1: with
  0.4.0 installed from the tap, a label was made with it (private store); `brew upgrade` through the reinstall stage
  replaced it (`dnm` and the app report 0.5.0 build 68); the label still showed, `dnm show` and `dnm list` read it,

  installed version) and was fixed after the tag.

  hand, from the unzipped download, shows no Gatekeeper dialog: **not done** (nor for 0.4.0); `spctl` and `syspolicy_check` accepted it.

## Review notes

Release range `v0.4.0..main` (2026-11-24), a code and security review by one fresh agent, read-only. No findings in
the code. High: `docs/release-notes/UNRELEASED.md` still held the empty-notes marker, which stops the notes composer
(fixed). Medium: the live kit's BUILD-INFO said macOS 26.0 (fixed); CodeQL builds on Xcode 26 against the 27.0
manifest (the run on the pushed commit is the check). Low: a few older plans and specs still mention macOS 26 as
history; the spec 001 quickstart the kit copies was updated; a test now pins the stand-in list.
