## Corrections during the release (2026-10-09)

- The composed release notes had the heading "New in this release" twice, because `UNRELEASED.md` carried its
  own copy of the heading that the composer adds. Before anything was pushed, the release commit was amended
  (`f72a529` became `6b7174b`), the signed tag `v0.1.1` was moved to it, and the zip was rebuilt, notarized and
  verified from it. The first build in the log below (SHA-256 `0eff026e…`) was superseded. Only the release notes
  differ between the two commits. Note for `UNRELEASED.md`: start with bullets, with no "New in this release"
  heading.
- The tap clone was one commit behind its remote and held unrelated uncommitted edits, so the cask was pushed
  from a separate clone (`56ad4be`, 2026-10-09).
- The `cask` stage's install-and-uninstall test uses the same cask name as the installed one, so it uninstalled
  the maintainer's own `dnm` from this Mac. Reinstalled from the published tap (`dnm --version` reported
  `0.1.1 (2)`). `scripts/release.sh` now refuses the `cask` stage while the cask is installed.
