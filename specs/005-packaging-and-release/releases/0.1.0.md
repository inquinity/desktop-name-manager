## Corrections during the release (2026-10-07)

- `verify` first failed: `syspolicy_check distribution` demands a stapled ticket, which a zip or bare binary
  cannot carry (FR-005). Fixed in `8c526da` (only "Notary Ticket Missing" is accepted). The signed tag
  `v0.1.0` was moved, before anything was pushed, from the release commit `ae6520d` to `8c526da`, and the
  zip was rebuilt, notarized and verified from that commit (its stamp names `8c526da`); the earlier builds
  in the log below were superseded. Only release tooling differs between the two commits.
- `cask` first failed: `brew audit --new` applies the official cask repository's popularity rules. Fixed
  in `2e1222f` (`--strict --online`). Homebrew then asked for `depends_on macos: :tahoe` instead of the
  deprecated `">= :tahoe"`; the template and the cask in the tap clone were corrected before the tap push.
- Follow-up: the `check` stage's "HEAD is the release commit" gate should accept tooling-only commits on
  top of the release commit.
